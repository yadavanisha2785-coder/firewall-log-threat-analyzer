About This Project

🛡️ Firewall Log Threat Analyzer

This application was developed as an educational cybersecurity project. It allows users to upload firewall log files and analyze network activity using rule-based detection algorithms to identify potentially suspicious behavior such as port scanning, brute-force attempts, DoS patterns, and unusual data transfers.

🎯 Objective

The objective is to demonstrate how defensive cybersecurity analysis works by parsing structured firewall logs, applying detection rules, calculating risk scores, and presenting results on a professional SOC-style dashboard — all inside a single static HTML file with no backend required.

⚙️ Technologies Used

HTML5 CSS3 Vanilla JavaScript Chart.js 4.4 FileReader API CSV Parsing

🔍 Detection Rules

The engine applies six rule-based detection algorithms:
Port Scan · Brute Force · DoS Pattern · Repeated Blocked Activity · Suspicious Port Usage · Unusual Data Transfer

📋 Supported Log Format

CSV files with columns: timestamp, source_ip, destination_ip, source_port, destination_port, protocol, action, bytes, status

⚠️ Important Limitation: This project is an educational rule-based log analyzer designed for learning purposes. It does not replace professional SIEM (Security Information and Event Management), IDS (Intrusion Detection System), IPS (Intrusion Prevention System), EDR (Endpoint Detection and Response), or commercial threat-intelligence platforms. All detections are heuristic and may produce false positives or false negatives.
